# 组会复盘：培养条件改变后细胞活性读数（预实验）

> 本次复盘目标：把证据边界讲清楚，而不是证明预设机制正确。汇报严格区分**观察、解释、限制、后续验证**四个板块。

## 一、观察（Observations）

1. **读数方向**：第一轮三个处理组各 3 孔（技术重复），仪器导出值尚未扣除空白（空白孔均值 0.08）。

   - 高剂量：0.63 / 0.60 / 0.66
   - 方向上：高剂量 < 对照 < 低剂量。
2. **形态**：高剂量组在显微镜下观察到细胞变圆、贴壁减少，仅有实验者文字记录，无标准化图像、无盲法计数。
3. **设备事件**：第二轮原计划隔天重复，因培养箱报警推迟；报警当天另一课题组也报告温度波动，但设备未保存连续温度曲线，无法判断细胞暴露于异常条件的准确时长。
4. **记录缺口**：高剂量配液由另一位同学完成，台账显示使用相同批号储备液，但具体稀释时间未填写；现有台账不足以重建每个操作分钟。

> 注意：计算相对活性前必须先统一扣除空白，不能混用已扣背景的数据和原始读数。

---

## 二、解释（Interpretation）——能下什么结论 / 还不能下什么结论

### ✅ 现在可以说的（描述性、方向性）
- 在**本次单次预实验**中，高剂量组活性读数方向上低于对照，低剂量组方向上高于对照。
- 高剂量组的形态变化（变圆、贴壁减少）与读数下降方向一致，可作为**待验证的旁证**。
- 当前数据**仅支持描述性均值与方向**的报告，适合在组会上展示原始点 + 空白扣除后的描述性均值。

### ❌ 现在不能下的结论
| 不能下的结论 | 原因 |
|---|---|
| 高剂量"显著"抑制活性 / 低剂量"显著"促进活性 | 仅一次独立实验；三孔为**技术重复**（同一次铺板、同一份培养物），不是独立生物重复；未预先确定主要比较与多重比较方法，不宜做显著性检验包装成可推广结论 |
| 低剂量"促进增殖" | 所用检测方法受细胞代谢状态影响，读数升高也可能来自单细胞代谢改变；且无无细胞对照排除试剂/处理物的光学或化学干扰 |
| 高剂量通过某条具体死亡通路（凋亡/坏死/代谢途径）起作用 | 未做凋亡、坏死或代谢途径的任何检测；形态观察无标准化图像和盲法计数，主观性强 |
| 培养箱温度波动是全部差异的解释 | 设备未保存连续曲线，无法确认暴露时长；不能把未经确认的设备问题直接当作全部差异的解释 |
| 可推广的总体效应量 / 剂量-效应关系 | 缺乏独立生物重复，无法估计总体效应；剂量范围也仅为预实验范围 |

## 三、限制（Limitations）

1. **重复类型**：每组 3 孔来自同一次铺板和同一份培养物，属技术重复，不能当作独立生物重复。
2. **对照缺失**：无溶剂对照、无无细胞干扰对照，无法排除试剂/处理物的光学或化学干扰。
3. **数据预处理**：仪器导出值尚未扣除空白（均值 0.08），需统一处理后再计算相对活性。
4. **设备记录**：培养箱报警当天无连续温度曲线，异常暴露时长不明。
5. **操作记录**：高剂量稀释时间未填写，台账不足以重建操作时间线；后续不能填入推测出来的时间点。
6. **统计计划**：尚未预先确定主要比较和多重比较处理方法。
7. **形态评估**：无标准化图像、无盲法计数，主观性较强。
8. **方法学**：现有活性检测方法受代谢状态影响，读数变化不能直接等同于细胞数量变化。

---

## 四、后续验证（Next Steps）

1. **独立重复**：重新铺板，在**不同日期**开展独立重复，每次保留技术复孔，先确认重复性，不急于扩展成大梯度矩阵；剂量沿用预实验范围。
2. **干扰排除**：每轮同时设置**溶剂对照**和**无细胞干扰对照**，排除试剂/处理物的光学或化学干扰。
3. **记录规范**：补充并统一记录配液、给药、读板时间，尽量统一等待时间；不填入推测时间点。
4. **数据预处理**：统一扣除空白后再计算相对活性，避免混用已扣背景与原始读数。
5. **统计计划**：在下一轮开始前预先确定主要比较和多重比较处理方法。
6. **方法学补充**：先解释现有方法测到了什么，再决定是否增加直接细胞计数；若增加第二种方法，注意样本若仍来自同一次培养，不会自动增加生物重复数量。
7. **机制研究**：是否继续凋亡/坏死/代谢途径等机制研究，取决于独立重复和干扰排除的结果，暂不预设。

## 五、一句话总结（可直接口头收尾）

> 这次预实验给了我们一个方向性的观察——高剂量读数下降、低剂量读数上升，形态变化方向一致；但因为只有技术重复、缺少无细胞对照、设备与操作记录不完整，我们**现在只能报告描述性趋势，不能下显著性、机制或可推广效应的结论**。下一步最重要的是独立重复、干扰排除和完整记录，机制研究是否继续要看这些结果。

# 研究计划：大学生判断短视频科普信息可信度的线索与情境变化

## 一、研究问题
本研究关注大学生在判断短视频中的科普信息是否可信时，实际使用哪些线索，以及这些线索在不同情境下是否发生改变。研究不再以“不同专业学生谁更容易相信错误信息”为核心问题，因为该表述容易先入为主，且“错误信息”的界定尚不明确。研究目标是通过理解判断过程，为媒介素养教育提出可检验的建议，而非证明某一专业学生更聪明。

## 二、方法选择：两阶段设计
研究暂定分两个阶段，顺序不可颠倒：

1. **第一阶段：半结构化访谈**
   - 目的：了解学生自己描述的判断过程，识别他们实际依赖的线索。
   - 对象：计划覆盖理工、社科和艺术等学习背景的学生。
   - 招募方式：采用有目的的招募与迭代分析，而非预先设定固定样本量。具体规模将结合分析饱和程度、可用资源和伦理审批要求调整。
   - 当前状态：尚无招募名单，样本量未确定。

2. **第二阶段：小规模情境实验**
   - 目的：在访谈基础上，检验特定线索对可信度判断的影响。
   - 设计思路：使用同一段内容的不同呈现版本，控制文字信息一致，仅改变来源说明或制作形式等单一变量，以区分不同线索的独立作用。
